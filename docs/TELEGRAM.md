# 봇에 다른 사람 초대

`@koreaeventalimi_bot` 1:1 대화는 초대가 안 된다. 각자 `/start` 하면 각자 채팅이 생긴다.

여러 사람이 같은 메시지를 받으려면:

1. 텔레그램에서 그룹 또는 채널을 만든다.
2. 그룹/채널에 `@koreaeventalimi_bot` 을 추가한다.
3. 채널이면 봇을 관리자로 둔다 (메시지 보내기 권한).
4. 그룹에서 아무 말이나 한 뒤, 봇이 그 채팅의 `chat_id` 를 쓰도록 루틴을 바꾼다.
5. 사람을 그 그룹/채널에 초대한다.

지금 발송은 개인 채팅이다. 공유용이면 그룹 `chat_id` 로 바꿔야 한다.
